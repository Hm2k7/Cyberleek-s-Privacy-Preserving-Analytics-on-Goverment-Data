# Cyberleek-s-Privacy-Preserving-Analytics-on-Goverment-Data
Privacy-preserving analytics on synthetic UAE hospital data. Differential privacy for population statistics and DP-FedAvg federated learning for 30-day readmission risk, across 3 hospitals that never share raw records. Includes membership-inference and differencing attacks, plus privacy-utility trade-off curves. Team Cyberleek.
